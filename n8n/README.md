# F32 — תזכורות יומיות

הקובץ `f32-reminders.workflow.json` הוא Workflow לא פעיל שיובא אל `https://n8n.goldsec.co.il`.

לפני הפעלה:

1. מחברים Supabase Credential עם Secret key ו-SMTP Credential של Mailjet.
2. מאמתים שכתובת הבדיקה המוגדרת בצומת Send Email נכונה.
3. מריצים ידנית עם נתוני בדיקה ורק אז מפעילים את ה-Schedule היומי.

ה-Workflow שולח מייל על מכרזי Go שמועד ההגשה שלהם בתוך שבעה ימים ועל סעיפים שמענה הלקוח שלהם הוא `review` ותאריך היעד הגיע. סעיף ללא תאריך אינו שולח מייל. אחרי שליחת תזכורת לסעיף מתעדכן `reminder_sent_at`, כדי שלא תישלח שוב לאותו יעד.

אין בקובץ Credentials או Secret. כתובת השולח, כתובת הבדיקה וקישור האתר אינם סודות.
